# Milestone 1 — рабочая основа MA

## Реализация

- Официальный CLI `@videojs/cli@10.3.0`: React, TypeScript, CSS, Scaffold, video.
- Настоящий `VideoPlayer` + `Video` из `@videojs/react/video`, версия 10.3.0.
- Локальный CC0 MP4 с аудиодорожкой и постером; источник и лицензия указаны рядом с медиа.
- Сохранены Scaffold Hotkey, Gesture, StatusAnnouncer и ErrorDialog.
- Работают play/pause, перемотка, текущее/полное время, mute/volume, fullscreen,
  скорость воспроизведения и PiP в поддерживаемом браузере.
- Основные элементы имеют 44px области нажатия; время остаётся видимым при 240px.
- Базовая палитра MA, системная типографика, контейнерная адаптивность,
  фокус, reduced motion и forced colors. Иконки — единый официальный набор Scaffold.
- Отдельная страница `ma.html` и сохранённый официальный workbench.
- GitHub Actions настроен на установку, проверку типов, сборку и браузерные тесты.

## Исправления

1. В текущем исходном Scaffold меню субтитров обращалось к `item.badge`, которого нет
   в опубликованных типах 10.3.0. Удалён только этот необязательный badge; меню сохранено.
2. Медиа передаётся через `Video src`: при недоступном файле браузер сообщает ошибку
   на video-элементе, и штатный ErrorDialog её отображает. При дочерних source-элементах
   исчерпание всех кандидатов не вызывало этот сценарий корректно.
3. Убрана кнопка Cast без подключённого расширения и сервиса; ненужный Mux-адаптер удалён.
4. У узких плееров сохранены оба времени, увеличены зоны нажатия и предотвращено
   наложение центральных кнопок на верхние/нижние панели.

## Проверки в текущей среде

| Команда | Результат |
| --- | --- |
| `npm ci` | PASS, чистая установка по lockfile |
| `npm run typecheck` | PASS |
| `npm run build` | PASS, три HTML-точки входа в dist |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test` | PASS, 10 браузерных тестов |
| `git diff --check` | PASS |
| lint | Скрипт не настроен в CLI-проекте |

Тестируется production build. Проверены реальное воспроизведение, пауза, окончание/повтор,
клавиатурная и указательная перемотка, время, mute/volume, fullscreen, скорость, Escape,
возврат фокуса, status announcer, 240/320/390px, touch-эмуляция телефона, недоступное медиа,
reduced motion, светлый/тёмный кадр, немецкие подписи и арабский RTL. Axe проверяет
WCAG 2 A/AA, 2.1 AA и 2.2 AA в выбранных состояниях — нарушений не обнаружено.
Ручная сертификация скринридером и испытания Safari/iOS на реальном устройстве не проводились.

Vite сообщает предупреждение о директиве `use no memo` внутри `react-compiler-runtime`.
Оно не прерывает сборку; браузерные проверки проходят.
