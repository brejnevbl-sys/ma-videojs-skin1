# Текущий выбор: два Pexels фильма

См. [PEXELS.md](PEXELS.md): точные исходники, локальные имена, конвертация и ограничения.
Публичная страница использует `apps/preview/src/films.ts`. Старый `demoFilm` ниже
сохранён только для технического preview/workbench и не подменяет фильмы Pexels.

# Замена демонстрационного фильма

Текущий MDN flower MP4 и его постер сохранены. Авторский 60-секундный ролик ещё
не добавлен, его длительность и права не объявляются проверенными.

1. Добавьте готовый MP4 и постер в `apps/preview/public/media/`, например
   `ma-film.mp4` и `ma-film-poster.jpg`. Предпочтителен MP4 с H.264/AAC и fast start
   (moov atom в начале файла), умеренным битрейтом для телефона.
2. Измените **только запись `demoFilm`** в `apps/preview/src/media.ts`:
   `src: sitePath('media/ma-film.mp4')`, `poster: sitePath('media/ma-film-poster.jpg')`,
   `title`, `description`, `attribution.label` и `attribution.url`.
3. Создайте файл атрибуции рядом с медиа: автор, название, права на изображение
   и звук, лицензия/разрешение. Уберите старую подпись MDN из новой записи;
   не называйте авторский фильм CC0 без отдельного решения владельца.
4. Запустите `npm run typecheck`, `npm run build` и Playwright. Тесты текущего
   sample явно проверяют его пятисекундную длительность, путь flower.mp4 и MDN;
   при реальной замене обновите эти ожидания на проверенные данные нового файла.
5. Проверьте 0:00 → 1:00, seek в начало/середину/конец, буферизацию, аудио/mute,
   fullscreen, постер, HTTP MIME `video/mp4` и byte ranges на хостинге, затем
   воспроизведение на реальном Android/iOS. Локальные проверки не заменяют production QA.

Управление в `src/video/` менять не нужно: Video.js получает длительность,
буферизацию, прогресс и ошибки из настоящего HTMLVideoElement. Одна конфигурация
используется главной страницей, `/ma.html`, preview и workbench. `Player` также
принимает типизированный `film` для другого встраивания.

Общие ссылки используют `sitePath` и Vite BASE_URL. Основной target — корень
домена (`base: '/'`), поэтому вложенный `/workbench/` не меняет пути медиа.
Для деплоя в подкаталог нужен абсолютный префикс base, например `/ma/`;
относительный `./` не предназначен для вложенных страниц этого проекта.

Apache 2.0 в корне относится к исходному коду. Лицензия видеоматериала задаётся
отдельно; текущая CC0-атрибуция MDN сохранена вместе с оригинальным sample.
