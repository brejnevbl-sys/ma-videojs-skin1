## Что проверено в браузере без подмены медиа

Добавлен `tests/real-films.spec.ts`. В нём нет `page.route`, mockPexelsMedia или
перехвата запросов. Production build отдаёт реальные файлы из Git.

На ширинах 240/390/1440px для **обоих** фильмов проверены:

- Native metadata duration, videoWidth/videoHeight и экранное время 1:00 / 0:14.
- Декодирование более трёх кадров и продвижение currentTime при воспроизведении.
- Пауза, pointer seek к 50%, клавиатурные End и Home.
- Правильный src постера, завершённая загрузка 960×540, JPEG MIME и SHA-256 ответа,
  совпадающий с соответствующим локальным JPG.
- MP4 MIME, HTTP 206, Content-Range и побайтовое соответствие первого KiB исходнику.
- Вход/выход из настоящего Chromium fullscreen.
- Переключение клавиатурой и обратно, неизменность документа и media-узла,
  сброс времени/пауза, сохранение mute, отсутствие горизонтального overflow.
- Axe WCAG A/AA в проверенном состоянии после возврата к основному фильму.

Ранее существовавшие тесты с явно обозначенными MDN транспортными фикстурами
сохранены для изолированных регрессий. Они больше не единственное доказательство
работы медиа: новые тесты требуют настоящие файлы и правильные длительности.

## Найденное и исправленное

- Переключение во время воспроизведения могло оставлять controls в состоянии
  playing/idle после нативного сброса src. Старый элемент теперь явно ставится на
  паузу **до** изменения src, через типизированный mediaRef; Video.js получает
  событие pause до регистрации нового источника. Новые unmocked тесты переключают
  реальный ролик во время playback и проверяют видимый Play, паузу и сброс времени.

- Оба фильма **без аудиодорожки**. Добавлена честная подпись “Silent film · no audio.”
  для каждой записи. Volume/mute остаются штатными controls и меняют состояние,
  но звука у этих файлов нет — это не ошибка воспроизведения.
- README/NOTICE и публичная атрибуция содержали устаревшие утверждения, что файлов
  нет. Они обновлены, сохранив авторов и отдельную Pexels License. Лицензия исходного
  кода Apache 2.0 не подменяет лицензию стоковых фильмов.

## Vercel Preview

Прямая ссылка из последнего комментария Vercel bot:
https://ma-videojs-skin1-git-feat-ma-pexels-films-brejnevbl-sys.vercel.app/

На исходном коммите bot сообщает Ready (обновление 2026-11-12 10:38 UTC). Прямые
запросы из этой среды отклонены **прокси до соединения с Vercel**: `403 Forbidden`,
`CONNECT tunnel failed, response 403`, сервер envoy. Поэтому доступность страницы,
playback и HTTP Range **на Vercel** здесь не подтверждены. Локальный Range/MIME тест
не выдаётся за проверку CDN. Для завершения live QA нужен доступ среды к этому хосту
или проверка владельцем с обычного браузера/Android. Ошибка не доказывает, что Vercel
недоступен пользователям или требует авторизации.

CI исходного `4f009c0` и PR run были зелёными после исправления browser installation.
CI новой ревизии следует проверять отдельно. Merge, новый PR, ручной deploy и отправка
на Contra не выполнялись.
