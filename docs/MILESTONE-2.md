# Milestone 2 — Visual Identity & Interaction Polish

Реализация по [Issue #2](https://github.com/brejnevbl-sys/ma-videojs-skin1/issues/2).
Ветка: `feat/ma-milestone-2`, база — актуальная `main` с принятым Milestone 1.

## Дизайн и реализация

- **Каллиграфическая шкала.** Авторский векторный силуэт в `src/video/brush.svg`
  формирует общий штрих. Сохранены настоящий Video.js TimeSlider, главы, буфер,
  прогресс, указатель, preview и клавиатурная семантика. Маска применяется только
  к видимому треку 12px; область seek имеет высоту 48px. Прогресс не интерполируется
  анимацией, поэтому положение отражает подтверждённое время медиа.
- **Самостоятельная идентичность.** MA и 間 находятся внутри плеера, рядом с
  спокойной брендовой типографикой. Открытое кольцо центрального play, тонкий
  указатель-печать и единая система окружностей связывают элементы управления.
  Палитра: #131313 / #F2E8D2 / #C06855. Иконки остаются единым семейством Scaffold.
- **Иерархия.** Редакционный системный serif, Mincho-fallback для японского знака,
  sans-serif для управления и моноширинные табличные цифры. Перекомпонована
  демонстрационная страница; внешний шрифт не загружается.
- **Состояния.** Центральный play уходит во время воспроизведения, сохраняя
  видимость при клавиатурном фокусе. Появление/скрытие панелей занимает 120/220ms;
  короткое перемещение ограничено 6px. Меню и popover используют 140ms переход.
  BufferingIndicator получил разомкнутое кольцо; настоящий ErrorDialog —
  редакционную типографику и акцентную линию.
- **Мобильная версия.** Нижняя панель остаётся доступной на coarse-pointer/touch
  даже при штатном idle-состоянии. На узких плеерах центральные дублирующие
  controls скрыты, а все обязательные операции и оба времени сохранены.
  Основные кнопки и пункты меню имеют цели не менее 44px. Отступы popup уменьшены,
  доступная высота используется эффективнее, длинные меню прокручиваются внутри.
- **Доступность.** Возврат фокуса volume после Escape выполняется через публичный
  `onOpenChange`; закрывающийся popup получает `inert` через render API, поэтому
  Tab не попадает обратно в исчезающий слайдер во время анимации. Сохранены
  Hotkey, Gesture, StatusAnnouncer, fullscreen и семантика ошибок. Reduced motion
  отключает движение, оставляя статическое обозначение загрузки. Forced colors
  заменяет маску сплошной шкалой.

Нового состояния воспроизведения, внешних сервисов или runtime-зависимостей не добавлено.
Сохранены `--media-accent-color`, `--media-border-radius` и возможность задать шрифт.
Маршруты не менялись: `/ma.html` — демонстрация, `/` — технический workbench.

## Фактически выполненные проверки

| Проверка | Результат |
| --- | --- |
| `npm ci` | PASS, чистая установка по существующему lockfile |
| `npm run typecheck` | PASS |
| `npm run build` | PASS |
| `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test` | PASS, 20 тестов |
| `git diff --check` | PASS |
| Lint | Отдельный скрипт не настроен |

Все 10 тестов Milestone 1 сохранены. Ещё 10 проверяют точность кликов по всей
48px области seek, Home/End/ArrowRight, полный Tab-порядок с динамическим volume,
Escape и следующий Tab, границы меню на 240/390px, touch dock, эмулированный
мобильный fullscreen, forced colors, reduced motion, реальную задержку загрузки
и восстановление playback, состояния paused/playing, светлый/тёмный кадр,
сохранение фокуса центральной кнопки, компактный widescreen и публичные CSS properties.
Снимки создаются на **production build**, а не на dev-сервере.

Axe не обнаружил нарушений WCAG A/AA в проверенных состояниях. Дополнительно по
вычисленным CSS-цветам проверен худший случай белого кадра под нижней панелью:
контраст пустой шкалы ≈3.02:1, прогресса ≈4.44:1, основного времени ≈14.30:1.
Это не заменяет ручной аудит с реальными скринридерами. Физические iOS/Android
для новой версии не тестировались; мобильная проверка выполнена в Chromium
с touch-эмуляцией. Пользователь подтвердил Android и Vercel для Milestone 1.

Существующее предупреждение Vite о `use no memo` в react-compiler-runtime остаётся
неблокирующим. Новых зависимостей и изменений package-lock нет.

## Публикация

Эта работа не объединяет ветку в main, не развёртывает Milestone 2 и не отправляет
конкурсную заявку. Существующий публичный сайт относится к Milestone 1; новая версия
предназначена для ревью в отдельной ветке. Статус удалённого CI нужно отличать от
локально пройденных проверок.
