# Milestone 3 — главная страница, workbench и подготовка фильма

Реализация текущего объёма [Issue #4](https://github.com/brejnevbl-sys/ma-videojs-skin1/issues/4)
с учётом уточнения владельца: авторский 60-секундный фильм будет подготовлен отдельно.
Ветка `feat/ma-milestone-3`, база `main` на `500689d`.

## Изменения

- `/` открывает MA с настоящим Video.js 10.3.0. Концепция и controls Milestone 2 сохранены.
- Workbench перенесён в статическую страницу `/workbench/`, содержит прежние настройки
  размера, соотношения сторон, языка/RTL, схемы, autoplay, mute, loop, preload и preferences.
  Параметры продолжают сохраняться в URL; iframe обновляется через postMessage.
- `/ma.html` сохранён как совместимый адрес MA, `/preview.html#...` — как независимый preview.
  Навигация работает в обе стороны. Единый `sitePath` предотвращает вложенные ошибочные
  запросы вроде `/workbench/media/flower.mp4` и `/workbench/preview.html`.
- Добавлен компактный About the skin с концепцией, технологией, лицензией и кредитами.
- Корневой `LICENSE` содержит полный стандартный Apache License 2.0 (включая приложение).
  Метаданные npm также указывают `Apache-2.0`; `NOTICE` сохраняет сведения Video.js,
  сторонних пакетов и отдельный CC0-статус текущего медиа.
- `apps/preview/src/media.ts` — единая типизированная запись видео, постера, названия,
  описания и атрибуции. Landing, alias, preview и workbench используют её совместно.
  Компонент Player принимает и отдельную запись `film`. Длительность получает из медиа
  Video.js; она не зашита в controls. [Инструкция замены](MEDIA.md).
- **Текущий flower.mp4, постер и CC0-атрибуция не изменены.** Новый фильм не добавлялся.
- Для прокручиваемых мобильных меню закреплена строка возврата, добавлены scroll-padding,
  обычная полоса прокрутки и overscroll containment. Сохранены 44px пункты меню и
  штатная навигация Video.js. На коротком плеере список прокручивается внутри popup.

Все 20 регрессий M1/M2 сохранены: play/pause, seek, время, mute/volume, fullscreen,
клавиатура, фокус, статус, ошибки, буферизация, reduced motion, forced colors и touch.
Шесть новых тестов проверяют обе страницы MA, возврат из workbench, воспроизведение
в iframe на вложенном маршруте, URL-параметры, изменение loop через UI, сохранение
после перезагрузки, открытие отдельного preview и мобильные меню на 240/320/390px.
Проверены настоящий touch swipe, прокрутка, достижение последней скорости клавиатурой,
выбор скорости касанием, Escape с возвратом фокуса и закрытие касанием снаружи.

Локальный production preview отдаёт MP4 с `Content-Type: video/mp4`, обрабатывает
Range-запросы ответом 206 и возвращает запрошенные 100 байт. Это проверка локальной
раздачи, а не утверждение о production CDN. Медиа и постер используют тот же origin;
проверка CORS внешнего будущего хостинга пока не проводилась.

Новых зависимостей нет. Lockfile изменён только для метаданных лицензии.
Отдельный lint script не настроен; существующее предупреждение Vite о директиве
`use no memo` в react-compiler-runtime не блокирует сборку.

## Границы готовности

Выполнены локальные проверки Chromium и touch-эмуляция. Реальный Android/iOS и ручная
проверка скринридерами для этой ревизии не подтверждены. Команды deploy, merge и
отправка на Contra не выполнялись; текущий production URL не подтверждает развёртывание
данной ветки. Удалённый CI необходимо отличать от локальных проверок.

Перед финальным релизом остаются: авторский ролик/постер/права, актуализация тестовых
ожиданий длительности sample, проверка MIME/ranges/seek на production, реальные телефоны,
официальный дедлайн и пользовательское ревью. Mux и конкурсная отправка не выполнялись.
